# v0.1.12 — 2026-11-22

A large program builds about seven times faster in less than half the memory,
`-O2` inlines by cost and no longer assumes AVX2, `try`/`catch`/`throw` in the
standard library, debuggers that can read what `-g` writes on Linux and
Windows, and a type check that no longer lets a value change in silence.

The full list is in [`CHANGELOG.md`](../../CHANGELOG.md); this is what most
programs will notice.

## Building is faster and smaller

A browser of 195 000 lines at `-O2 -j 4` went from 23 s and 537 MB to about
3 s and under 200 MB. A body is parsed, analyzed, lowered and dropped in its
turn, IR stays packed until it is read, and only what `main` reaches gets code.
`docs/build-perf.md` has the figures.

The compiler no longer leaves a `.s` beside every source it compiles; nothing
read them. `--emit-asm` asks for the file, and `--no-asm-cache` is gone.
`--obj-cache <dir>` reuses a module's object when its key has not changed.

An edit could be built into the old program: source hashes were djb2, which
cannot tell `"0b"` from `"1A"`, so the caches served the file from before the
edit. They are FNV-1a over 64 bits now.

## `-O2`

**Inlining by cost.** The fixed limits (60 instructions, 6 arguments, no frame)
are replaced by a threshold per call site, raised in loops, for a callee's only
call and per constant argument, with a growth budget per caller. Callees that
keep a frame are inlined too. `-O1` is unchanged.

**`--cpu=` says what `-O2` may assume.** The default is now `x86-64`: SSE2 only,
no CPU test at run time. `auto` is what `-O2` did before, `x86-64-v3` is AVX2
with no test, and `znver3` adds the code layout tuned on Zen 3. A program that
wants AVX2 now asks for it.

Three vectorizer bugs are fixed: a loop with a way out besides its test was
vectorized and skipped it; without AVX2, `x[i] = x[i] + z[i]` stored into `z`;
and code with no AVX2 test could fault on a CPU with only SSE2.

Float literals are now the nearest double. The parser rounded once per fraction
digit, so `0.0015` could be two ulps off.

## Exceptions

`std/exceptions.cst` brings `try`/`catch`/`throw` without an `_Unwind_*`
runtime, so static binaries with no libc can use them. `throw` runs every guard
it unwinds past, and the catch resumes in the frame that called `begin`. An
uncaught throw runs nothing on its way out: it stops, printing the value and a
frame-pointer backtrace. Tested on Linux
x86_64 at every level, AArch64 under qemu and Windows under wine.

## Debuggers can read the output

On Linux, `-g` writes DWARF: gdb and lldb get the source, breakpoints by
`file:line`, stepping, backtraces, locals, arguments and types. `.eh_frame` and
`.eh_frame_hdr` carry real frame information, shared objects included.

On Windows, the `.pdb` was unreadable by every debugger. Its types, its
container and its module stream are fixed, and each object gets its own module.
Locals read correctly at every optimization level and parameters from the first
breakpoint, enums have a debug type, and AArch64 has call frame information.

## Limits that failed in silence

Many fixed tables in the compiler, the assembler and the linker dropped what
did not fit without a word: a 33rd parameter, a 65th `defer`, a `break` 33
loops deep, the 257th import, the 33rd custom section. They grow now, or refuse
with an error. Input nested thousands of levels deep is refused with
`error: nesting too deep` instead of crashing the compiler, and a short write is
no longer reported as a successful build.

## Upgrading

The type check is stricter, and code that compiled before can be refused:

- `let`, `return`, assignment and every call now share one rule. A float does
  not become an integer or the other way round, and an integer is not narrowed
  without a cast. An `f64` passed for an `i64` used to compile, and the callee
  read a register the value was never put in;
- a function stored into, or passed as, an `fn(...)` type must have that
  signature, parameter by parameter and the return type.

Every refusal is a value that was being changed silently, so the fix is the
cast that says so, or the type that was meant.

A static link that leaves a symbol unresolved is now an error, not a warning:
a program that calls into a library without naming it (`-lc`, `-lm`, ...) used
to link into a binary that crashed. Name the library. `--shared` and links with
`-l` still allow undefined symbols.

`-O2` no longer uses AVX2 unless asked: add `--cpu=auto` for the old behaviour,
or `--cpu=x86-64-v3` for AVX2 with no test.
